# 妖怪銭湯 / Yokai Bathhouse

終電のあと、妖怪たちを湯船へ案内するオフラインのターン制パズル。初代本編は手作りの十二晩、妖怪八種、日本語・英語、最終夜のエンディングを収録。

## 遊び方

`dist/index.html` を Edge / Chrome などで開く。ZIPで受け取った場合は全ファイルを同じフォルダーに展開してから開く。インストール、通信、サーバーは不要。中断・最高記録はブラウザに保存される。ファイルの移動、別ブラウザ、プライベートモード等では記録を引き継げない場合がある。

先頭の客を案内する、湯を調整する、客を別の湯船に移す、待つ、のいずれかで一手。好みの条件を二手連続で満たすと満足して帰る。相席、壊れた釜、乾燥する夜などを乗り越え、各晩の目標を満たすと次の晩が開く。

## 開発・検証・配布

v1.5では全12晩に2枚ずつ、合計24枚のおもてなし札を追加。全員満足と晩ごとの特別条件を達成すると、妖怪の絵つきの札を帳面に収録する。札は任意で、通常クリアだけで次の晩が開く。目標達成後は閉店ボタンで記録を確定でき、操作を取り消すとその手の挑戦条件への影響も取り消される。

v1.4では「1手戻す」を追加。案内・移動・温度調整・待機の直前に戻せる。営業中に中断・再開しても直前の1手は残る。閉店後は結果画面を離れるまで戻せ、最高記録と解放済みの晩は保持する。

5名の再レビューを反映し、初夜の案内例、設定温度と実際の湯温の違い、詰んだときに戻す手順、連続で取り消せない理由、閉店後の取り消し期限を日英で明示した。スマホでは固定の営業状況欄にボタンを配置。

v1.3では、ヒントの探索、複数タブでの保存、スマホでの結果通知とフォーカス、妖怪の表情を修正。オフライン用は `dist/YokaiBathhouse-v1.3.zip`。

v1.2では、待ち客と入浴中の妖怪をイラストで表示。湯温に応じて湯気や水色が変わり、妖怪の表情で快適さが分かる。動きを減らす端末設定にも対応。

v1.1では、次の客と各湯船をまとめた固定表示を追加。「ヒント」から考え方を、「次の一手を見る」から現在の盤面で目標に届く手を確認できる。ヒントを開いても手数は消費しない。

- ビルド不要。`dist` 内の HTML、CSS、JavaScript が配布用ファイル。
- ルールと全十二晩の攻略経路：`node verify.cjs`
- 実ブラウザ検証：`npm ci` の後、Microsoft Edge がある環境で `npm run test:browser`。環境変数 `BATHHOUSE_PLAYWRIGHT` で別の Playwright モジュールを、`BATHHOUSE_URL` で HTTP 配信先を指定できる。
- GitHub Pages は Settings → Pages の Source に GitHub Actions を選ぶ。公開前にサブパス配信で起動と攻略を検証する。
- 本編のローカル配布版。Steam提出用ビルド、ストア登録、無料体験版の別パッケージは含まない。

## 5名の独立レビュー

| 担当 | 主な反映 |
|---|---|
| 難易度 | 全晩の攻略経路を確認。序盤の手数を緩和、目標未達が確定した場合に再挑戦を案内。判定時と退浴後の湯温を分けて表示 |
| ルール | 河童は先頭に出た次の手から待ち時間を数える。複数の退店通知を併記し、不正な操作は無視 |
| 保存 | 一覧から再読込しても再開可能。破損データを除外し、別タブの言語変更や古い中断状態で記録を失わないよう分離・保護 |
| 操作性 | 画面切替時に見出しへフォーカス。操作名に客と湯船を含め、案内ボタンの近くに好みを表示。読み上げ用通知領域を維持 |
| 英語・物語 | 列の先頭と河童の皿の表現を明確化。第2晩から第11晩と終幕につながる常連の会話を追加 |

### v1.3の再レビュー

- ルール・ヒント：第10晩で初手に湯船1を冷ました局面を再現し、別の探索順を追加。第3晩は火車の退浴前後を明記。
- 保存：対応ブラウザでは Web Locks でタブ間の保存を直列化。既存の中断がなければ、古いタブから始めた新しい営業も保存できる。
- スマホ・操作性：ターンの結果を固定欄に表示。操作後は同じ湯船の操作に戻り、ヒントを常設の読み上げ欄で通知。
- 表情・演出：直前の快適判定に合わせて表情を変え、次の手の湯温や相席の不足を文言で区別。湯温が同じなら湯気の動きを継続。
- テスト・配布：ブラウザ検証の依存を固定。Pages の配信経路で公開前テストを実行し、配布 ZIP を更新。
